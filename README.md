# Hackpad

A custom macropad designed and built as a Hack Club Stardance project.

## Features

* Custom PCB
* Custom 3D-printed case
* Programmable firmware
* Has 3 buttons 
* Registers 1,2,3

## Hardware

* Microcontroller:MOUDLE-SEEEDUINO-XIAO
* Switches: SW_Push
* PCB designed in KiCad
* Case designed in Fusion 360
