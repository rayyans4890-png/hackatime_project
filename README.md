# My Hackpad

This is a custom Hackpad I made for Hack Club Stardance.

I designed the PCB, made a case for it, and added firmware so all of the switches can be programmed to do different things.

## Features

* 5 switches
* Custom PCB
* Custom firmware
* USB connection

## Tools Used

* KiCad
* Fusion 360
* QMK Firmware 

## Firmware

The firmware is included in this repository. It is used to make the switches work and can be changed to give the buttons different functions.

The compiled firmware is also in the `production` folder.

## Files

The `production` folder contains the files needed to make the Hackpad:

* `gerbers.zip` - PCB manufacturing files
* Case files
* Compiled firmware

The rest of the repository contains the PCB, case, and firmware source files.

## Testing

I tested the finished Hackpad to make sure all 5 switches register correctly and that the PCB, firmware, and case all work together.
